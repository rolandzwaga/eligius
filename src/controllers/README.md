# Controllers

This is a list of all the available controllers with links to their respective documentation

- [DOMEventListenerController](https://rolandzwaga.github.io/eligius/classes/DOMEventListenerController.html "This controller attaches to the given selected element and adds a DOM event listener for the specified event name that executes the given actions with the given operation data.")

- [KeyboardController](https://rolandzwaga.github.io/eligius/classes/KeyboardController.html "This controller runs the given actions when one of the given keys is pressed.")

- [LabelController](https://rolandzwaga.github.io/eligius/classes/LabelController.html "This controller attaches to the given selected element and renders the text associated with the given translation key.")

- [LottieController](https://rolandzwaga.github.io/eligius/classes/LottieController.html "This controller renders a [lottie-web](https://github.com/airbnb/lottie-web) animation inside the given selected element.")

- [MutationObserverController](https://rolandzwaga.github.io/eligius/classes/MutationObserverController.html "Controller that observes DOM mutations on a selected element and broadcasts events.")

- [NavigationController](https://rolandzwaga.github.io/eligius/classes/NavigationController.html "Renders a navigation menu in the selected element and keeps it in sync with the active navigation entry.")

- [ProgressbarController](https://rolandzwaga.github.io/eligius/classes/ProgressbarController.html "This controller renders a progressbar that displays the progress of the current timeline in the given selected element.")

- [RoutingController](https://rolandzwaga.github.io/eligius/classes/RoutingController.html "Keeps the browser history in sync with the navigation entries: each entry gets a `#/<id>/<position>` URL, and back/forward navigation requests the entry in the URL.")

- [SubtitlesController](https://rolandzwaga.github.io/eligius/classes/SubtitlesController.html "This controller shows the subtitle whose duration contains the current timeline position in the selected element, in the current language, and re-renders it after a `language-change` event.")
