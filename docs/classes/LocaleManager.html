    setLocale

    • setLocale(locale: `${Lowercase<string>}-${Uppercase<string>}`): void

      Sets the current locale and emits a change event.

      If the requested locale has not been loaded (and at least one locale has), a warning is logged and the default locale is used instead.

      Setting the locale that is already current (after any fallback) is a no-op: no event is emitted, so listeners that react by switching the locale again cannot cause a loop.

      Parameters

      • locale: `${Lowercase<string>}-${Uppercase<string>}`

    t

    • t(
          key: string | string[],
          params?: Record<string, unknown>,
          locale?: `${Lowercase<string>}-${Uppercase<string>}`,
      ): string

      Retrieves a translation for the given key.

      The key must name a leaf translation: a string, or a function that returns a string. Every other case returns an empty string (and logs a warning in debug mode):

      • the key does not exist as own properties of the locale data (inherited members such as constructor or toString do not count);
      • the key names a namespace (a nested object) rather than a leaf;
      • a function translation returns something other than a string.

      Parameters

      • key: string | string[]

        The translation key (string or array of strings for nested keys)

      • Optionalparams: Record<string, unknown>

        Optional parameters for interpolation

      • Optionallocale: `${Lowercase<string>}-${Uppercase<string>}`

        Optional locale override (uses current locale if not specified)

      Returns string

      The translated string, or an empty string if the key does not name a string translation

      Throws

      Whatever a function translation throws

      Example

      localeManager.loadLocale('en-US', {nav: {home: 'Home'}});
      localeManager.t('nav.home'); // 'Home'
      localeManager.t('nav'); // '' (namespace, not a leaf)
