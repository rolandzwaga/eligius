    Class EngineFactory

    The EngineFactory is used to create and initialize an IEligiusEngine instance.

    It prepares a resolved configuration and creates the engine based on the class defined in the configuration.

    Example: Loading a configuration and creating an IEligiusEngine instance

    import { IEngineConfiguration, EngineFactory, EligiusResourceImporter } from 'eligius';
    import * as engineConfig from './my-eligius-config.json';

    const factory = new EngineFactory(new EligiusResourceImporter(), window);

    const { engine } = factory.createEngine((engineConfig as unknown) as IEngineConfiguration);

    engine.init().then(()=> {console.log('Eligius engine ready for business');});

    createEngine

    • createEngine(
          configuration: IEngineConfiguration,
          resolver?: IConfigurationResolver,
      ): IEngineFactoryResult

      Creates a fully wired engine with adapters and event handlers.

      This method:

      • Resolves the configuration
      • Creates timeline providers
      • Instantiates the engine and locale manager
      • Creates and connects adapters for eventbus integration

      Unless the factory was given an eventbus, the engine gets an eventbus of its own, so several live engines from one factory do not answer each other's requests or react to each other's commands. When this method throws, nothing it registered is left on the eventbus and pending external locale loads are aborted.

      External ($ref) locales are loaded with a 30 second timeout per file. Destroying the engine (through the returned destroy() or engine.destroy()) aborts loads that are still pending, disconnects the adapters and removes the engine's eventbus registrations.

      • configuration: IEngineConfiguration

        The engine configuration

      • Optionalresolver: IConfigurationResolver

        Optional custom configuration resolver

      Returns IEngineFactoryResult

      Engine result with engine, locale manager, eventbus, and destroy function

    createTimelineProvidersByUri

    • createTimelineProvidersByUri(
          configuration: IResolvedEngineConfiguration,
          providersByType: Record<TimelineTypes, ITimelineProviderInfo>,
      ): Record<string, ITimelineProviderInfo>

      Creates the timeline provider for every timeline, keyed by timeline URI.

      The first timeline of each type reuses the provider created for that type by createTimelineProvidersForConfig. Every other timeline gets its own position source, constructed with its own duration, and shares the type's container provider and playlist.

      A timeline whose positionSource or containerProvider override changes the settings of its type gets that component built from the merged settings (see ITimelineConfiguration.positionSource). The components it does not override, and the playlist, come from its type.

      Position sources that render their own DOM container (they implement IContainerProvider, like VideoPositionSource) take their duration from the media rather than from the timeline. They are shared by all timelines of a type with the same effective settings, so switching timelines does not create a second player; a timeline whose override changes the video settings gets a player of its own. Overridden container providers are shared the same way.

      Parameters

      • configuration: IResolvedEngineConfiguration

        The resolved engine configuration

      • providersByType: Record<TimelineTypes, ITimelineProviderInfo>

        The providers created per timeline type

      Returns Record<string, ITimelineProviderInfo>

      A record of timeline URIs to their provider info

      Throws

      Error when a position source or container provider cannot be imported, or an overridden position source has no systemName

    • createTimelineProvidersForConfig(
          configuration: IResolvedEngineConfiguration,
      ): Record<TimelineTypes, ITimelineProviderInfo>

      Creates timeline providers for all configured timeline types using the new configuration-driven architecture.

      This method iterates over timelineProviderSettings and creates a ITimelineProviderInfo for each configured timeline type by:

      1. Finding the first timeline that matches the type, skipping timelines whose positionSource override changes the type's settings (when every timeline of the type has one, the first timeline is used)
      2. Using the timeline's duration for the position source
      3. Assembling components from the settings
