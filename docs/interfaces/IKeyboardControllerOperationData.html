    keys

    keys: string

    The keys that run the actions, in hotkeys-js syntax: comma separated shortcuts such as 'right', 'shift+right' or 'space, enter'. Key names are case insensitive. Accepted are the hotkeys-js names (left, up, right, down, space, enter, esc, tab, backspace, del, ins, home, end, pageup, pagedown, f1 to f19, num_0 to num_9), the KeyboardEvent.key names of the same keys (ArrowLeft, ArrowUp, ArrowRight, ArrowDown, Enter, Escape, Tab, Backspace, Delete, Insert, Home, End, PageUp, PageDown, F1), a single letter or digit, and the punctuation keys , . / ; ' [ ] - =. ' ' (the KeyboardEvent.key of the space bar) means space. Modifiers: shift, alt (option), ctrl (control) and meta (cmd, command).
