    Interface RequestMap

    The request/response queries that Eligius itself answers through IEventbus.onRequest, with the arguments each takes and the value it returns. Generated from the event interfaces in src/eventbus/events that declare a returns property.

    Querying one of these names with IEventbus.request (without an explicit type argument) types the response, and registering a responder for one with IEventbus.onRequest checks the signature. The untyped string overloads remain for custom request names.

    interface RequestMap {
        "request-action": { args: [actionName: string]; returns: IAction };
        "request-current-language": {
            args: [];
            returns: `${Lowercase<string>}-${Uppercase<string>}`;
        };
        "request-current-timeline-position": { args: []; returns: number };
        "request-engine-root": { args: []; returns: JQuery<HTMLElement> };
        "request-function": { args: [systemName: string]; returns: unknown };
        "request-instance": { args: [systemName: string]; returns: unknown };
        "request-translation": {
            args: [key: string | string[], params?: Record<string, unknown>];
            returns: string;
        };
        "timeline-container-request": {
            args: [];

        };
