    • on<K extends "change">(
          event: K,
          handler: (...args: LocaleEvents[K]) => void,
      ): () => void

      Subscribe to locale events.

      Handlers are isolated: one that throws is logged with console.error and the others still run, so setLocale() does not throw because of a handler. A handler added while an event is being emitted is first called for the next event.
