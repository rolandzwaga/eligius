    Interface IEligiusResourceRegistrations

    Custom resources to register with the EligiusResourceImporter, keyed by system name.

    Every name has to be unique across all the maps. A name that is already provided by Eligius itself (an operation, controller, timeline provider, eventbus export or EligiusEngine) is rejected, unless override is true.

    Example

    const importer = new EligiusResourceImporter({
      operations: {trackEvent},
      functions: {formatPrice: data => {data.price = `€ ${data.amount}`;}},
      controllers: {ChartController},
      templates: {intro: '<div class="intro"></div>'},
      json: {chartData: {labels: ['a', 'b'], values: [1, 2]}},
    });
