    Interface ITimelineConfiguration

    Configuration for a single timeline.

    A timeline represents a time-based sequence of actions that can be played, paused, and seeked. Multiple timelines can exist in a configuration.

    Example

    const timeline: ITimelineConfiguration = {
      id: 'main-timeline',
      uri: 'timeline://main',
      type: 'animation',
      duration: 60,
      loop: false,
      selector: '#timeline-container',
      timelineActions: []
    };

    OptionalpositionSource

    positionSource?: Partial<IPositionSourceConfig>

    Optional position source settings for this timeline only, merged over timelineProviderSettings[type].positionSource.

    • Leave out systemName (or repeat the type's) to change single settings, for example only the selector of a scroll timeline. The other settings of the type still apply.
    • Name a different systemName to give this timeline another kind of source, for example a ScrollPositionSource chapter in a configuration whose animation timelines use RafPositionSource. The type's position source settings are then not used, and when every timeline of a type does this, the type needs no timelineProviderSettings entry.

    A source that renders its own container (VideoPositionSource) is shared by every timeline of the type with the same effective settings, so only an override that changes the video settings creates a second video element. Other sources are created once per timeline, as without an override.

    Example

    {"positionSource": {"systemName": "ScrollPositionSource", "selector": "#chapter-2"}}
