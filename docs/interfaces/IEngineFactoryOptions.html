    Optionaleventbus

    eventbus?: IEventbus

    An eventbus for every engine the factory creates. Without it, each engine gets its own eventbus (returned as IEngineFactoryResult.eventbus), so engines never answer each other's requests or react to each other's commands.

    Use one live engine per eventbus: request responders such as request-engine-root are answered by the first engine that registered them, and commands such as timeline-play-request reach every engine on the bus. The factory warns when a second engine is created on a shared eventbus while another one is live.

    Optionalinput

    input?: IEngineInputOptions

    Keyboard and window input bindings for every engine the factory creates. Leave it out for the defaults: space toggles playback, and a window resize broadcasts timeline-resize.

    Example

    // An embedded widget: no page-wide space key, no resize listener
    new EngineFactory(importer, window, {
      input: {playToggle: 'k', scope: 'engineRoot', resize: false},
    });
