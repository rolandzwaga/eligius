    Variable whenConst

    when: TOperation<IWhenOperationData, Omit<IWhenOperationData, "expression">> = ...

    When the given expression evaluates to false, subsequent operations will be skipped until an endWhen or otherwise operation is encountered.

    Practically, this means an if or if/else statement control flow implementation in a list of operations.

    The expression is passed in as a formatted string. An operand can be one of:

    'constant': for a constant string (operators and parentheses inside the quotes are text) 100: for a constant number (the whole operand must be numeric, 10px is invalid) true, false, null: for a boolean or null constant $operationData.foo: for an operation data value $globaldata.foo: for a global data value $scope.loopIndex: for a scope value $scope.variables.foo: for a variable set with setVariable

    Any other operand is an error, so a misspelled chain prefix fails instead of being compared as a string.

    Operands are combined with these operators, from highest to lowest precedence:

    !: negation ==, !=, >, <, >=, <=: comparison (== and != compare strictly, without type conversion; comparisons do not chain, so write 0<$scope.loopIndex && $scope.loopIndex<5) &&: and ||: or

    Parentheses group. A bare operand is true when its value is truthy, so 'false' and '0' are true and 0, '', null and a missing value are false. !, && and || always produce true or false. ! binds tighter than a comparison: !$operationdata.a==1 compares !$operationdata.a with 1, write !($operationdata.a==1) to negate the comparison. && and || short-circuit: when the left side decides the result, the right side is not resolved, so $operationdata.user && $operationdata.user.name=='John' does not fail when user is missing.

    Arithmetic (+, -, *, /) is not supported: - is a valid character in a property chain, so $operationdata.a-1 would be ambiguous. Nothing in the expression is executed as code, and property chains are resolved with the usual prototype-pollution and global-object guards.

    Example

    $scope.variables.foo=='bar'

    Example

    $operationdata.isValid==true

    Example

    Example
